# Resolución de 23 de octubre de 2018, de la Presidencia del Comisionado para el Mercado de Tabacos, por la que se publican los precios de venta al público de determinadas labores de tabaco en Expendedurías de Tabaco y Timbre de la Península e Illes Balears

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

En virtud de lo establecido en el artículo 4 de la Ley 13/1998, de 4 de mayo, de Ordenación del Mercado de Tabacos, y normativa tributaria se publican los precios de venta al público de determinadas labores de tabaco en Expendedurías de Tabaco y Timbre de la Península e Illes Balears, que han sido propuestos por los correspondientes fabricantes e importadores.

###### Primero.

Los precios de venta al público de las labores de tabaco que se indican a continuación, incluidos los diferentes tributos, en Expendedurías de Tabaco y Timbre de la Península e Illes Balears, serán los siguientes:

|  | Precio total de venta al público – Euros/cajetilla |
| --- | --- |
| A) *Cigarrillos* |  |
| American Spirit Blue | 5,15 |
| American Spirit Orange | 5,15 |
| American Spirit Yellow | 5,15 |
| Benson & Hedges American Red 100 | 4,15 |
| Benson & Hedges Option | 4,30 |
| Camel Activa | 4,85 |
| Silk Cut Blue | 5,15 |
| Silk Cut Purple | 5,15 |
| Silk Cut Purple 100’S | 5,15 |
| Silk Cut Silver | 5,15 |
| Silk Cut White | 5,15 |
| Winston Expand | 4,60 |
| Winston Silver | 4,75 |
| Winston Xstyle Gold | 4,60 |

|  | Precio total de venta al público – Euros/envase |
| --- | --- |
| B) *Cigarros y cigarritos* |  |
| Neos: |  |
| Mini Java (el envase de 5) | 1,20 |
| Mini Red Filter (el envase de 5) | 1,20 |

|  | Precio total de venta al público – Euros/unidad |
| --- | --- |
| C) Picadura de pipa |  |
| Del Mar North (40 g) | 2,90 |
| Del Mar South (40 g) | 2,90 |

###### Segundo.

La presente Resolución entrará en vigor el mismo día de su publicación en el «Boletín Oficial del Estado».

**Madrid, 23 de octubre de 2018.–La Presidenta del Comisionado para el Mercado de Tabacos, Isabel Eugenia Juliani Fernández de Córdoba.**
