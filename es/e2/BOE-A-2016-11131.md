# Resolución de 25 de noviembre de 2016, de la Presidencia del Comisionado para el Mercado de Tabacos, por la que se publican los precios de venta al público de determinadas labores de tabaco en Expendedurías de Tabaco y Timbre de la Península e Illes Balears

> **This is the law as enacted. Amendments are not incorporated below — each one is
> a separate file in this repository and a commit in this file's history.**

En virtud de lo establecido en el artículo 4 de la Ley 13/1998, de Ordenación del Mercado de Tabacos, se publican los precios de venta al público de determinadas labores de tabaco en Expendedurías de Tabaco y Timbre de la Península e Illes Balears, que han sido propuestos por los correspondientes fabricantes e importadores.

###### Primero.

Los precios de venta al público de las labores de tabaco que se indican a continuación, incluidos los diferentes tributos, en Expendedurías de Tabaco y Timbre de la Península e Illes Balears, serán los siguientes:

|  | Precio total de venta al público – Euros/cajetilla |
| --- | --- |
| A) *Cigarrillos* |  |
| Bullbrand Negro (40) | 7,85 |

|  | Precio total de venta al público – Euros/unidad |
| --- | --- |
| B) *Cigarros y cigarritos* |  |
| Gurkha: |  |
| Cellar 12 Platinum Hedonism G. Robusto (20) | 12,00 |
| Cellar 12 Platinum Kraken XO (20) | 13,40 |
| Cellar 12 Platinum Solara Dbl Robusto (20) | 11,00 |
| Verellen: |  |
| Poncho (10) | 0,20 |

|  | Precio total de venta al público – Euros/envase |
| --- | --- |
| C) *Cigarros y cigarritos* |  |
| La Galera: |  |
| Half Corona Habano (el envase de 5) | 18,50 |

|  | Precio total de venta al público – Euros/unidad |
| --- | --- |
| D) *Picaduras de liar* |  |
| Raw Authentic Tobacco Original Green (50 g) | 8,60 |
| E) *Picaduras de pipa* |  |
| El Holandes pic. pipa lata (85 g) | 5,95 |
| Jameston pic. pipa lata (70 g) | 4,95 |

###### Segundo.

La presente Resolución entrará en vigor el mismo día de su publicación en el «Boletín Oficial del Estado».

**Madrid, 25 de noviembre de 2016.–El Presidente del Comisionado para el Mercado de Tabacos, Juan Luis Nieto Fernández.**
